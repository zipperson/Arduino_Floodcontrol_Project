# Trash Diversion System
https://drive.google.com/file/d/1TasrW_lMbnPOkqcf758IUg2pfHCljEkF/view?usp=sharing

# Description
Trash diversion system to be used by private institutions. Was to be implemented in brgy Labangon with necessary letters already signed, however prototype was destroyed by flood Tino thus deprecated

# Mechanism
Uses an waterproof ultrasonic sensor (jsn-sr04t) to detect movement and remove debris from canals via a conveyor system
